Backups are crucial for protecting your data from catastrophic loss and preparing a recovery procedure. The chef-automate backup create command creates a single backup that contains data for all products deployed with Chef Automate, including Chef Infra Server and Chef Habitat Builder on-prem . By default, Chef Automate stores backups to the filesystem in the directory /var/opt/chef-automate/backups .
