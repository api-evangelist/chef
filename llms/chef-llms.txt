# Chef (Progress Chef)

> Chef provides infrastructure automation, compliance, and application delivery tooling. Chef exposes REST APIs for the Infra Server (nodes, cookbooks, roles, environments, data bags), Chef Automate (convergence, compliance scans, reports, IAM), Habitat Builder (application package delivery), and InSpec (security and compliance testing).

This llms.txt was generated by API Evangelist from the Chef APIs.json index; Chef does not publish its own llms.txt (docs.chef.io/llms.txt returns 404).

## APIs

- [Chef Infra Server API](https://docs.chef.io/server/api_chef_server/): Manage nodes, cookbooks, roles, environments, data bags, clients, and users. RSA signed-header authentication.
- [Chef Automate API](https://docs.chef.io/automate/api/): Compliance profiles, scan jobs, report search, config-management nodes, and IAM. API-token authentication.
- [Chef Habitat Builder API](https://docs.habitat.sh/docs/using-builder/): Origins, packages, and channels for Habitat application delivery. Bearer-token authentication.
- [Chef InSpec](https://docs.chef.io/inspec/): Open-source language and runner for security and compliance testing, consumed via the InSpec CLI and surfaced in Automate.
